Every Screen — Full Feature Detail

🚀
Screen 1 — Splash & Onboarding
First thing user sees on install
SCREEN
  • 🎬
    Animated logo + 3 onboarding slides
    Swipeable intro cards: "YouTube only for what matters", "AI filters distractions automatically", "Create your focus workspace". Skip button available on slide 2+.
  • ⚙️
    Silent AI model pre-warming
    While user reads the 3 slides, MobileBERT + MobileNet load into GPU memory. By the time user finishes onboarding, AI is warm and ready. User sees nothing — it's invisible.
  • 🏷️
    Forced first workspace creation
    After onboarding, user must create at least 1 workspace. Cannot enter app without it. Workspace creation screen opens automatically.
🏠
Screen 2 — Home (Workspace Tabs + Video Feed)
The main screen — most of user's time here
CORE SCREEN
  • 📑
    Workspace tabs bar
    Max 5 tabs shown horizontally. Each tab = workspace name + color dot. Active tab is highlighted. Tap to switch instantly. Long-press to rename/delete. "+" button at the end to add new workspace.
  • 🎥
    2-column video feed grid
    Each video card: thumbnail (full width of column), channel name, video title (2 lines max), view count, duration badge. Same density as YouTube app.
  • 🔴
    Blur/cover layer on unproductive videos
    AI-blocked videos: thumbnail is blurred (Gaussian blur), title text replaced with "Not in focus category", lock icon on card, semi-transparent colored overlay matching workspace color, not tappable. Long-press shows "Report this?" option.
  • 💀
    Skeleton loading cards
    Before AI finishes, grey shimmer placeholder cards fill the grid instantly. Videos appear one by one as scored — progressive loading. Never shows blank screen.
  • 🔄
    Pull-to-refresh + auto-refresh
    Pull down → fresh YouTube fetch + re-filter. Auto-refreshes every 30 minutes in background while app is open. Badge on tab shows "New videos" when background refresh finds new content.
  • 🔍
    Search bar
    Search within the current workspace category. Results ALSO go through AI filter — no distracting results even in search.
  • 🤖
    Floating AI Assistant button
    Round button bottom-right. Tap → AI chat opens as bottom sheet overlay without leaving the feed. Dismiss by swiping down.
  • ⏱️
    Active timer mini-bar (conditional)
    Only shows when a timer is running. Thin colored bar at top of screen with time remaining. Tap it to go to full Timer screen.
➕
Screen 3 — Create / Edit Workspace
Modal screen — appears on first launch and when adding tabs
MODAL
  • ✏️
    Workspace name input
    Text field with placeholder "e.g. Study, Trading, Coding…". Max 20 chars. Auto-suggests name based on category chosen.
  • 🏷️
    Category tag chips (multi-select)
    Grid of selectable chips: Education, Mathematics, Programming, Science, Trading, Finance, Design, Fitness, Language, History, Engineering, Medicine, Chess, Music Theory. Select 1–5. These become YouTube search keywords.
  • 🎨
    Workspace color + icon picker
    8 color options + emoji icon picker for the tab. Makes each workspace visually distinct at a glance.
  • 🎚️
    Filter strictness slider
    Slider: Relaxed (40) → Balanced (60, default) → Strict (80). Shows preview text: "At 80, only highly relevant videos pass. At 40, borderline videos also show."
▶️
Screen 4 — Video Player
Opens on tapping a productive video card
SCREEN
  • 📺
    In-app YouTube embed player
    Video plays inside app via YouTube embed URL in WebView. No switching to YouTube app. Full-screen tap. Landscape auto-rotate. Back button returns to feed at same scroll position.
  • 📊
    AI Score breakdown badge
    Below video: "Productivity Score: 84/100". Expandable to show: Text Score (MobileBERT): 87 | Image Score (MobileNet): 76 | Final: 84. User understands why video was allowed.
  • 🚩
    "Not Productive" report button
    For videos that passed filter but user thinks shouldn't have. Tapping this helps app learn over time. Score adjusted in local database.
  • 📝
    Quick note field
    Collapsible text area below player. User jots notes while watching. Saved per video ID in Room database. Persistent across sessions.
🔍
Screen 5 — Report Video (Deep AI Check)
MiniLM-L6 deep-checks a blocked video when user challenges it
AI — MiniLM-L6
1

User long-presses a covered/blocked video

Bottom sheet appears: "Think this video is relevant to your [Study] workspace?" → "Yes, check again" button.

2

App fetches full video data

Downloads full description + captions/transcript via YouTube API. Loading screen: "Fetching full video content…" ~1–2 seconds.

3

MiniLM-L6 reads everything

Full title + description + captions (~3,000–15,000 words) fed to MiniLM. "Deep analyzing…" shown. ~1.5–2 sec processing.

4

Verdict screen shown to user

✅ "Confirmed productive for [Study]. Video unblocked." OR ❌ "After full analysis, this video is outside your focus category. Stays blocked."

5

Score saved to local database

Updated score stored per video ID. Next time this video appears → instant decision from cache, no re-analysis needed.

🤖
Screen 6 — AI Productivity Assistant
SmolLM2-360M + MCP tools — opens as bottom sheet
AI — SmolLM2
  • 💬
    Chat interface with message history
    User types, AI responds in 1–2 sec (on-device). Chat bubbles: user right, AI left. Conversation saved per workspace. Each workspace has its own chat history.
  • 🛠️
    MCP Tool Cards in chat
    When AI creates something, a tool card appears in chat (not just text). Card shows: what was created, preview, "Activate" button. E.g. card: "⏱ 25-min Pomodoro Timer — [Activate]".
  • ⚡
    Quick prompt chips
    4 suggestion chips before user types: "Start Pomodoro", "Plan my session", "What is Deep Work?", "Make a to-do list". Tapping fills input — no typing needed.
  • 🎯
    Workspace-aware responses
    "Plan my session" in Study workspace → AI makes a study schedule. Same prompt in Trading workspace → AI makes a trading prep list. AI always knows active workspace context.
  • 📖
    Productivity rule explanations
    User asks "What is the 80/20 rule?" → AI explains: definition, how to apply it today, benefits, common mistakes. Full explanation on-device, no internet.
📚
Screen 7 — Productivity Rules Library
Browse, learn, and apply focus rules — AI explains each
AI — SmolLM2
  • 🃏
    Rules grid (9 rules)
    Cards for: Pomodoro Technique, 80/20 Rule, Deep Work, Time Blocking, 2-Minute Rule, Eat The Frog, Flow State, 1-3-5 Rule, MIT (Most Important Tasks). Each card: rule name + icon + 1-line tagline.
  • 📖
    Rule detail page (tap any card)
    SmolLM2 generates: What is this rule? Step-by-step how to use it. Benefits. Common mistakes. All on-device, no internet needed.
  • 🎬
    "Visual Explanation" button
    Opens Screen 8. Gemini 2.0 Flash generates an animated HTML page with moving diagrams explaining the rule visually. Cached after first load.
  • ▶️
    "Apply This Rule Now" button
    One tap → SmolLM2 auto-creates the complete setup for that rule: timers, to-do list, and planner already filled in. User immediately has a working system.
🎨
Screen 8 — Visual Explainer
Animated HTML explanation rendered in WebView — Gemini API
GEMINI API + FALLBACK
  • 🌐
    Full-screen in-app WebView
    Gemini returns self-contained HTML + CSS animations + JavaScript. Rendered in a WebView fullscreen inside the app. No browser opens. Feels like a native animated screen.
  • ✨
    What the animation looks like
    CSS keyframe animations, SVG diagrams, interactive step-through walkthroughs, 3D-style perspective effects, all explaining the concept visually. E.g. Pomodoro → animated 25-min circle with phases.
  • 📦
    Offline fallback (SmolLM2)
    No internet / API limit hit → SmolLM2 generates simpler HTML on-device. Less fancy animation, same information. User never sees an error — fallback is invisible.
  • 💾
    Permanent cache per rule
    Once generated, HTML stored in local database. Next view = instant load. Gemini API only called once per rule per device. Zero repeat API cost.
🛠️
Screens 9, 10, 11 — To-Do, Timer, Planner
Productivity tools — created manually or by SmolLM2 via MCP
MCP TOOLS
  • ✅
    To-Do List (Screen 9)
    Add tasks manually OR AI populates from chat. Tap to check off. Swipe to delete. Tasks organized per workspace. Completed tasks collapsed at bottom. Task count badge on bottom nav.
  • ⏱️
    Timer Screen (Screen 10)
    Large circular countdown ring. Tap to pause/resume. Pomodoro auto-cycle mode (25m focus → 5m break → repeat → 30m long break after 4 cycles). Custom timer creator. Vibration + notification at phase changes. Mini-bar shows on Home when running.
  • 📅
    Daily Planner (Screen 11)
    Time-block schedule for today. Hourly rows, drag to resize blocks. AI fills it based on tasks + workspace. Color-coded by workspace. Tap block to start timer for that session.
  • 🤖
    How AI creates these via MCP
    User says in chat "Plan a 2-hour study session" → SmolLM2 outputs JSON MCP call → app creates 4× Pomodoro timers + empty task list + 2-hour planner block → all appear instantly. User just taps "Activate".
⚙️
Screen 13 — App Settings
Global controls and preferences
SCREEN
  • 🔒
    Strict Mode toggle
    ON = zero override. Covered videos cannot be long-pressed or challenged. No report button visible. Maximum lockdown.
  • 🎚️
    Global filter threshold slider
    Master level affecting all workspaces (unless overridden per-workspace). Range 20–90.
  • 🌓
    Theme — Light / Dark / System
    Three-way toggle. "System" follows phone's dark mode setting automatically.
  • 🗑️
    Clear AI score cache
    Delete all saved video scores → app re-runs AI filter fresh on next load. Useful if filter feels outdated.
  • ℹ️
    About + AI model info
    Shows: app version, which AI models are installed + their sizes, total storage used by the app.
03

4 On-Device AI Models + 1 Free API

1
Text Classifier

MobileBERT INT8

Reads video title → gives 0–100 productivity score per workspace category. Batch processes all 150 titles at once on GPU.

25 MB
Every video load
2
Vision Classifier

MobileNetV3-Small INT8

Looks at thumbnail image → detects if visual is educational (whiteboard/code/chart) or distracting (clickbait face/party/gaming). 35% weight in final score.

4 MB
Every thumbnail
3
Deep Check

MiniLM-L6 INT8

Reads full captions + description (up to 15,000 words). Used only when user reports a blocked video. Gives a deep, accurate verdict. Loads on-demand only.

22 MB
Report only
4
On-Device LLM

SmolLM2-360M INT4

Conversational AI. Explains productivity rules, answers questions, and outputs MCP JSON to create timers/tasks/planners inside the app. Fully offline.

180 MB
AI chat + rules
API — Needs Internet

Gemini 2.0 Flash (Free)

Called only for Visual Explainer screen. Generates animated HTML explanations. Free: 1500 requests/day. Falls back to SmolLM2 when offline. Results cached permanently after first call.

TOTAL APP SIZE
~274 MB

Well under your 300 MB budget. 25+4+22+180+43 (code+assets+libs) = 274 MB.

04

User Experience — What They See vs What Happens

Productive Video Card

User sees →

Normal thumbnail + title. Tappable. AI Score "87/100" badge visible. No friction, just watch.

Behind the scenes →

MobileBERT: 87 + MobileNet: 76 → Fusion: 83. Above threshold (60). Shown normally.

Unproductive Video Card

User sees →

Blurred thumbnail. "Not in focus category" text. Lock icon. Not tappable. Long-press shows "Report?" option.

Behind the scenes →

MobileBERT: 28 + MobileNet: 42 → Fusion: 33. Below threshold. Blur layer applied.

Reporting a Blocked Video

User sees →

Long-press → "Check Again" → loading 2s → "✅ Confirmed productive. Unblocked."

Behind the scenes →

MiniLM loads → reads 4,000 words of captions → topic detected as algebra tutorial → score updated to 78 → saved to DB → blur removed.

AI Creates a Timer

User sees →

"Start Pomodoro for exam prep" → AI chat shows timer card → tap "Activate" → Timer screen with 25-min countdown.

Behind the scenes →

SmolLM2 → MCP JSON: create_timer(1500s, "Exam Prep") → Room DB stores it → Timer screen loads from DB.

Navigation Structure

BOTTOM NAV (always visible):
🏠 Home  |  ⏱️ Timer  |  ✅ To-Do  |  📚 Rules  |  ⚙️ Settings

HOME:
→ Tap workspace tab → feed switches (stays on Home)
→ Tap "+" → Create Workspace (modal slides up)
→ Tap video card → Video Player screen
→ Long-press blocked card → Report modal
→ Tap floating AI button → AI Chat (bottom sheet)
→ Tap mini-timer bar → Timer screen

RULES:
→ Tap rule card → Rule Detail page
→ "Visual Explanation" → WebView fullscreen
→ "Apply Rule" → AI auto-creates timer + task list

AI CHAT (bottom sheet):
→ Tool card "Activate" → navigates to Timer / To-Do / Planner
